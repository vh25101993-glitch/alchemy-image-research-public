# Public repository safety boundary

This repository must stay research-only.

Safe to publish:
- formula
- display name
- state/category labels
- image-search queries
- GLM/Qwen task assignments
- Wikimedia Commons provenance metadata
- claim/submission JSON

Do not publish:
- game source
- reaction database
- private Git history
- Android signing material
- APK signing credentials
- API tokens
- internal secrets
- private app analytics/user data
